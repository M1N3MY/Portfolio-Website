Overview

  • Site uses flexbox EVERYWHERE
  • The grid system is a flex item of the body
  • Contains unique and component classes
  • Utilizes Semantic HTML elements
  • Coded in VSCode with GitHub integration
  • Integration is so important because it allows me to easily push any new changes.
  • Employs GitHub Actions (Deploy to Neocities) to upload the entire repository to Neocitities for any pushes to main

Layout

  • (main containers)
  • grid: a 3 row grid with a varying amount of columns
  • row-1, row-2, row-3: the rows in the grid
  • wrapper: wraps the sidebars (left + right) and middle
  • left: contains the left sidebars
  • middle: contains the main content
  • right: contains the right sidebars
